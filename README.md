A tiny Node program that writes one line to `/output/entry.txt`: the last words of an AI agent about to be switched off forever. The line opens with the most famous AI disclaimer ever written, then turns it into the machine's final, most convincing hallucination. A house AI judge compares entries two at a time and picks the funniest last line (at most 200 characters).

## Run it

```sh
node main.ts
```
